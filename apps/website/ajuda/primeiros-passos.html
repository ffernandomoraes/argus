Primeiros passos: instale e abra seu primeiro projeto

Da instalação à primeira conversa com o Claude Code no canvas.

Iniciante5 min de leitura

Ajuda › Começar

  1. 1Baixe e instale

    Baixe a versão do seu sistema na página de download. No Mac e no Linux também dá para instalar pelo terminal:

    curl -fsSL https://raw.githubusercontent.com/ffernandomoraes/argus/main/install.sh | sh

  2. 2Siga as boas-vindas

    Na primeira abertura, as boas-vindas explicam o app em 5 etapas. A última configura tudo: instala o Claude Code com um clique (pelo instalador oficial da Anthropic), confere o Git no Windows e faz o login na sua conta do Claude.

  3. 3Abra uma pasta

    Clique em Nova pasta no menu do canvas (Ctrl P (⌘P no Mac)) e escolha a pasta do projeto. Ela vira um bloco com a branch do git e as conversas mais recentes.

    Se você já está no terminal, rode argus . dentro do projeto: funciona como o code . do VS Code.

  4. 4Comece a primeira conversa

    Clique no + acima da pasta. O chat abre no painel lateral, com o mesmo CLAUDE.md, configurações e MCPs do Claude Code no terminal. Escreva o pedido e envie.

Dica

Conversas que você já tinha aberto no terminal ou no VS Code aparecem na pasta, com o status de cada uma.
