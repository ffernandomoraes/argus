A new release almost every day

How Argus ships: an automatic release for every change and one-click updates.

Behind the scenesJoão AndradeOct 31, 2026

Blog › Behind the scenes

Argus ships a new release almost every day. That only works because publishing and updating take no effort, neither for the people building it nor for the people using it.

A release for every change

Every change to the main branch becomes a release: the version number goes up and the change titles become the release notes, as short bullet points. Before publishing, the tests run on Mac, Windows and Linux, and the app is launched in a smoke test.

One-click updates

The app checks for a new version when it opens and every 5 hours, and downloads it in the background. Once it's ready, "Update to" shows up in the title bar. One click restarts the app on the new version.

No lost permissions

On Mac, every release is signed with the same certificate, and the app only accepts an update signed by it. That way, the permissions you granted (microphone, notifications) keep working in later versions.

The notes for each release are on the changelog page.
