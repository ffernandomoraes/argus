Por que um canvas para acompanhar agentes de código

Dez abas de terminal não escalam. O que muda quando cada projeto vira um bloco.

ProdutoJoão Andrade31 de outubro de 2026

Blog › Produto

Quem trabalha com agentes de código conhece a cena: uma aba de terminal por projeto, uma conversa esperando resposta em algum lugar, outra que terminou há vinte minutos sem ninguém perceber. O trabalho ficou paralelo, mas as ferramentas continuaram uma janela de cada vez.

O problema não é o agente, é a visão de conjunto

Cada conversa com o Claude Code é ótima sozinha. O que falta é responder, num relance, três perguntas: o que está rodando, o que terminou e o que está esperando por mim. Num terminal, isso exige abrir aba por aba.

Um bloco por projeto

No Argus, cada pasta vira um bloco no canvas, com a branch do git, os arquivos não comitados e as conversas mais recentes. A cor e a etiqueta de cada conversa mostram o status: rodando, esperando você ou concluída. Os subagentes aparecem embaixo da conversa que os lançou, enquanto trabalham.

Espacial, como o resto do seu trabalho

Designers organizam telas num canvas há anos. Projetos e agentes também cabem nesse modelo: grupos para trabalho, freela e pessoal, notas soltas, terminais ao lado das pastas. A organização é sua, e o app guarda.

O resultado é simples: você para de caçar abas e passa a olhar para uma tela só.
