What's new.

A new version ships almost every day. Here are the latest changes, straight from the releases.

v0.1.103Oct 31, 2026
  • FixWindows: updating no longer leaves Argus uninstalled; closing the app doesn't install, only "Update to" does
  • ImprovementStorage tab: "Clean up now" shows only how much can be freed and the last cleanup; the details are behind the info icon
v0.1.102Oct 30, 2026
  • ImprovementDeleting a chat also deletes the agent's drafts, the file restore points and its terminal environment
v0.1.101Oct 30, 2026
  • ImprovementStorage tab shows separately what takes up space and what's past its retention period, and "Clean up now" says how much it will free and what it freed
v0.1.100Oct 30, 2026
  • NewMemory and disk warning next to the Argus name (with what stopped for lack of them) and a Storage tab with automatic cleanup of chats, screenshots and agent drafts
  • FixUpdating or closing Argus no longer erases what was done, and anything that was working comes back marked as interrupted (red dot) with a "Continue where it left off" button
v0.1.99Oct 30, 2026
  • ImprovementUpdated dependencies with security issues flagged by Dependabot (undici, qs and fast-uri)
  • NewMark a chat as unread (right-click in the list or the chat's three-dot menu): the dot turns green again until you reopen it
  • NewClicking an image pasted in the message box opens it full size before sending
  • NewClicking background tasks (on the canvas or "View output" in the chat) opens each one's live output in a read-only drawer
v0.1.98Oct 29, 2026
  • FixA minimized window, one behind others or with the screen locked no longer shows up as a hang in Sentry when the computer wakes or the screen unlocks
  • FixOn Mac, an Argus dialog opened with no window in focus (like the prompt on close) no longer shows up as a hang in Sentry
  • FixThe "Claude usage not updating" warning no longer goes to Sentry at the end of the wait requested by the usage API, before the retry
v0.1.97Oct 28, 2026
  • FixAn idle window with the CPU throttled by the system (power saving on Windows, temperature on Mac) no longer shows up as a hang in Sentry
  • FixThe "Claude usage not updating" warning no longer goes to Sentry while Argus is just waiting out the delay requested by the usage API
v0.1.96Oct 28, 2026
  • NewClicking a subagent (on the canvas or "View chat" in the chat) opens everything it did in a read-only drawer
  • FixIn focus mode, canvas groups no longer flash for a few frames when scrolling the chat
v0.1.95Oct 28, 2026
  • FixOn Windows, Claude reads the right terminal output even after the panel is resized, closed and reopened, and gets the right exit code from PowerShell
  • FixValues that aren't secrets ("private": true, keywords, sessionTimeout) no longer turn into *** in the terminal output Claude reads
  • NewClaude runs commands in the chat's terminal and reads the output; secrets reach it as ***
  • New.md files created by Claude show up formatted in the chat, with the path, "Show all" and "Open alongside"
v0.1.94Oct 27, 2026
  • NewA sent message can be edited right in its bubble and resent at the end of the chat; if Claude is replying, it stops and the new version runs next
v0.1.93Oct 27, 2026
  • ImprovementHang reports no longer blame a hidden window (covered by another, minimized or with the screen locked), and a real hang while it's hidden is still reported
v0.1.92Oct 27, 2026
  • FixA background task or subagent finishing no longer triggers a "Done" notification
v0.1.91Oct 27, 2026
  • FixOn Windows and Linux, open dropdown lists are readable in the dark theme
  • FixOn Windows, the close button of an enlarged image no longer sits under the window buttons
  • ImprovementOn Windows and Linux, the workspace picker sits at the left end of the title bar
  • FixCode opens with syntax highlighting in the code panel again, including Dockerfile and Makefile on Windows
  • FixWith tools running in parallel, the chat step no longer shows as "Running: undefined"
  • NewOn Windows, the Running servers panel appears and shows what's running in the canvas folders; the menu no longer wraps item names
  • NewNew Notifications section in settings: turn system notifications and their sound on or off
v0.1.90Oct 26, 2026
  • New.md files in the code panel have a formatted preview; ⌘⇧V (Ctrl+Shift+V) toggles it with the source
  • NewClaude's plan shows up formatted in the chat, with "Show all" and "Open alongside" in a larger window
v0.1.89Oct 26, 2026
  • FixClaude usage no longer stalls silently: the check has a timeout, the panel rechecks when opened and shows why when it doesn't update
  • FixThe chat no longer disappears when resizing the window, the panel or the drawer zoom
  • FixThe Mac close, minimize and maximize buttons sit in the middle of the title bar, aligned with the workspace picker

Every version at github.com/ffernandomoraes/argus/releases.
