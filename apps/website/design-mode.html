◇Design mode

From comment to finished screen, in real code.

Open your project's page inside Argus, click any element and leave a comment. Comments go along with your next request, and Claude updates the project's code.

Prototype in the project, not in a mockup

Comments pinned to elements

Click a spot on the page and type. The bubble stays pinned to the element, along with its path in the code.

Desktop and mobile

Switch views with one click and see the same page at both sizes.

Text snapshot

Every request carries the URL, the view and a text snapshot of the screen, without spending tokens on images.

New or existing screen

Describe a screen from scratch or open an existing one to tweak it.

Multiple apps

In projects with a site, admin and app in the same dev script, pick which one to open.

Server under control

The project's server never starts on its own: the button sits right next to the chat.

Comment

Point, type, send.

Turn on “Comment”, click the elements you want to change and write what you need. When you send, Claude gets each comment tied to the right element.

Get started

Up and running in under 5 minutes.

No API key and no server in the middle. Download, open your folders and go.

  1. 1

    Download Argus

    macOS, Windows or Linux, straight from the GitHub releases.

  2. 2

    Sign in with Claude

    Argus uses the claude on your machine and the subscription you already have.

  3. 3

    Open a folder

    Drag it onto the canvas or run argus . in the terminal.
