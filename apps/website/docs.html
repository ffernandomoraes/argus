Getting started

Install

Download the build for your system on the download page. On Mac and Linux you can also install from the terminal with install.sh.

First launch

The welcome screens walk you through the app in 5 steps. The last one sets everything up: it installs Claude Code in one click (Anthropic's official installer), checks for Git on Windows and signs you in to your Claude account.

Open a folder

Use New folder in the canvas menu (Ctrl P, or ⌘ P on Mac), drag a folder onto the window or run argus . in the terminal from inside the project. The folder becomes a block on the canvas with its git branch and latest chats.

Start a chat

Click the + above the folder. The chat opens in the side panel, with the same CLAUDE.md, settings and MCPs as Claude Code in the terminal.

Concepts

Canvas

An infinite workspace with pan and zoom. It remembers the position, size and color of everything on it.

Group

A colored region that gathers folders, terminals and chats: Work, Freelance, Personal or whatever you like. Each group uses one Claude account.

Folder

A folder on disk, shown as a block. It displays the name, path, branch and latest chats; the rest are under View all chats.

Chat

A chat with Claude Code running in the folder. It takes text, screenshots, files and dictation. Status: running, waiting on you or done.

External session

A chat started outside the app (terminal, VS Code). Argus shows its history and status in the folder.

Agent and subagent

Agents are Claude Code subagents, in ~/.claude/agents, called with @name. While a subagent runs, it shows up under the chat that launched it.

Terminal

A block with a real terminal in a folder, running claude or the system shell.

Account

A Claude login. The main one is the one in ~/.claude, the same as in the terminal; others are added in Settings › Accounts.

Chats

Where they open

In the side panel, in their own window or in a block on the canvas, depending on Settings › General › Open chats in. A chat lives in only one place at a time.

Permissions

Permission requests arrive in the chat, with the full command and the diff of the edit. Pick each chat's permission mode at the bottom of the message box.

Model and effort

Change the model, effort level, thinking and Ultracode per chat. Each chat keeps its own.

Commands and agents

Type / for slash commands and @name to call an agent from the library.

Accounts

One account per group

Right-click the group and choose the account. The group's folders, terminals and chats use it; outside any group, the default account applies.

Adding accounts

In Settings › Accounts: add, sign in again, nickname, set as default and remove. History, CLAUDE.md, agents and skills stay linked to the main account's.

Usage limit

The indicator in the title bar shows each account's limit without spending usage to check it.

Design mode

Turn it on

Design mode is an experiment: turn it on in Settings › Experiments. Then use New design from the folder's right-click menu.

New or existing screen

Describe a screen from scratch or open a page that already exists. The page from the project's server opens inside the app, with the chat alongside.

Comment

Turn on Comment, click an element and type. Comments go along with your next message, together with the element's path.

Terminals and code

Terminals

Right-click the folder › New terminal here › Claude Code or Shell. Use focus mode to enlarge it and Ctrl + / Ctrl - for the font size.

Project server

The button above the folder runs the dev or start script from package.json. The Running servers list also shows the ones agents left running.

Code panel

File tree and editor with git colors. Create, rename, delete, and save with Ctrl S.

Where data lives

Claude Code files

WhatWhere
Chat~/.claude/projects/<project>/<session>.jsonl
Status of open sessions~/.claude/sessions/<pid>.json
Global agents~/.claude/agents/*.md
Added accounts~/.argus/accounts/<id>

Argus reads these Claude Code files; they aren't a public API and may change between versions.

Updates

The app checks for a new version when it opens and every 5 hours. When it's ready, Update to appears in the title bar.
