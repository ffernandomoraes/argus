Primeiros passos

Instale

Baixe a versão do seu sistema na página de download. No Mac e no Linux também dá para instalar pelo terminal com o install.sh.

Primeira abertura

As boas-vindas explicam o app em 5 etapas. A última configura tudo: instala o Claude Code com um clique (o instalador oficial da Anthropic), confere o Git no Windows e faz o login na sua conta do Claude.

Abra uma pasta

Use Nova pasta no menu do canvas (Ctrl P, ou ⌘ P no Mac), arraste uma pasta para a janela ou rode argus . no terminal, dentro do projeto. A pasta vira um bloco no canvas com a branch do git e as conversas mais recentes.

Comece uma conversa

Clique no + acima da pasta. O chat abre no painel lateral, com o mesmo CLAUDE.md, configurações e MCPs do Claude Code no terminal.

Conceitos

Canvas

Área de trabalho infinita, com pan e zoom. Guarda a posição, o tamanho e a cor de tudo o que está nela.

Grupo

Região colorida que junta pastas, terminais e conversas: Trabalho, Freela, Pessoal ou o que você quiser. Cada grupo usa uma conta do Claude.

Pasta

Uma pasta do disco representada por um bloco. Mostra o nome, o caminho, a branch e as conversas mais recentes; as demais ficam em Ver todas as conversas.

Conversa

Chat com o Claude Code rodando na pasta. Aceita texto, prints, arquivos e ditado. Status: rodando, esperando você ou concluída.

Sessão externa

Conversa aberta fora do app (terminal, VS Code). O Argus mostra o histórico e o status dela na pasta.

Agente e subagente

Agentes são os subagentes do Claude Code, em ~/.claude/agents, chamados com @nome. Enquanto um subagente roda, ele aparece embaixo da conversa que o lançou.

Terminal

Bloco com um terminal real numa pasta, rodando o claude ou o shell do sistema.

Conta

Login do Claude. A principal é a do ~/.claude, a mesma do terminal; as outras são adicionadas em Configurações › Contas.

Conversas

Onde abrem

No painel lateral, numa janela própria ou num bloco dentro do canvas, conforme Configurações › Geral › Abrir conversas em. Uma conversa fica em um lugar só de cada vez.

Permissões

Os pedidos de permissão chegam no chat, com o comando completo e o diff da edição. Escolha o modo de permissão de cada conversa no rodapé da caixa de mensagem.

Modelo e esforço

Troque modelo, nível de esforço, thinking e Ultracode por conversa. Cada conversa guarda os dela.

Comandos e agentes

Digite / para os comandos de barra e @nome para chamar um agente da biblioteca.

Contas

Uma conta por grupo

Clique com o botão direito no grupo e escolha a conta. Pastas, terminais e conversas do grupo usam ela; fora de grupo vale a conta padrão.

Adicionar contas

Em Configurações › Contas: adicionar, entrar de novo, apelido, padrão e remover. Histórico, CLAUDE.md, agentes e skills ficam ligados aos da conta principal.

Limite de uso

O indicador na barra de título mostra o limite de cada conta, sem gastar uso para conferir.

Acesso remoto

Ligar

No computador que fica ligado, abra Configurações › Acesso remoto e ligue Permitir acesso. Com o acesso ligado, o computador não dorme; dá para desligar em Manter este computador acordado.

Parear

Em Parear um aparelho, clique em Gerar código. No outro computador, use Conectar a outro Argus e digite o código; no celular, aponte a câmera para o QR code. O código vale por 10 minutos, para um aparelho só.

Usar

No notebook, o Argus de casa abre numa janela com a barra de cima azul: canvas, conversas, terminais e arquivos. No celular: uso das contas, conversas e projetos, pedidos por texto, voz, foto ou arquivo e avisos quando uma conversa termina ou pede permissão.

Segurança

A conexão é criptografada de ponta a ponta. A barra de cima mostra quantos aparelhos estão conectados; em Aparelhos pareados, remova os que não usa mais.

Terminais e código

Terminais

Botão direito na pasta › Novo terminal aqui › Claude Code ou Shell. Use o modo foco para ampliar e Ctrl + / Ctrl - para a fonte.

Servidor do projeto

O botão acima da pasta roda o script dev ou start do package.json. A lista Servidores rodando mostra também os que os agentes deixaram no ar.

Painel de código

Árvore de arquivos e editor com as cores do git. Crie, renomeie, exclua e salve com Ctrl S.

Onde ficam os dados

Arquivos do Claude Code

O quêOnde
Conversa~/.claude/projects/<projeto>/<sessão>.jsonl
Status das sessões abertas~/.claude/sessions/<pid>.json
Agentes globais~/.claude/agents/*.md
Contas adicionadas~/.argus/accounts/<id>

O Argus lê esses arquivos do Claude Code; não são API pública e podem mudar entre versões.

Atualizações

O app procura versão nova ao abrir e a cada 5 horas. Quando ela fica pronta, aparece Atualizar para na barra de título.
