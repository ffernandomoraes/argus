Baixe o Argus.

Grátis. Roda na sua máquina, com o Claude Code e a assinatura que você já tem.

Baixar para o seu sistema

Atualiza sozinho depois de instalado.

Baixar .dmg ou o .zip

Windows

Windows 10 e 11, 64 bits

Baixar instalador Sem pedir administrador

64 bits (Intel e AMD)

Baixar AppImage Um arquivo só

Mac e Linux

Ou instale pelo terminal.

Baixa a última versão, coloca no lugar certo e abre. Rodar de novo atualiza. No Mac, assim o app abre sem o aviso de desenvolvedor não identificado.

Terminal 
$ curl -fsSL https://raw.githubusercontent.com/ffernandomoraes/argus/main/install.sh | sh

Instalação

Passo a passo.

  1. 1

    Baixe o .dmg

    O arquivo Argus-versão-arm64.dmg, no botão acima.

  2. 2

    Arraste para Aplicativos

    Abra o .dmg e arraste o Argus para a pasta Aplicativos.

  3. 3

    Libere na primeira vez

    O app não é notarizado pela Apple. Em Ajustes do Sistema › Privacidade e Segurança, clique em Abrir Mesmo Assim.

  1. 1

    Baixe o instalador

    O arquivo Argus-Setup-versão.exe, no botão acima.

  2. 2

    Abra o arquivo

    Na primeira vez, o Windows mostra “O Windows protegeu o computador”. Clique em Mais informações › Executar assim mesmo.

  3. 3

    Instale o Git

    O Git for Windows mostra os arquivos alterados e o diff. As boas-vindas do app conferem para você.

  1. 1

    Baixe o AppImage

    O arquivo Argus-versão-x86_64.AppImage, ou use o comando do terminal acima.

  2. 2

    Dê permissão

    Rode chmod +x no arquivo e abra. Na primeira abertura o Argus entra no menu de apps.

  3. 3

    Tenha o git

    O git da distribuição mostra os arquivos alterados: sudo apt install git.

Antes de começar

O que você precisa.

Claude Code

O Argus usa o claude da sua máquina e a sua assinatura. Se ainda não tiver, as boas-vindas instalam com um clique e fazem o login.

Git

Para a branch, os arquivos não comitados e o diff. No Windows, o Git for Windows; no Linux, o da distribuição.

Outros agentes, se quiser

Codex, Gemini CLI e Cursor CLI também funcionam. Conecte em Configurações › Contas.

Depois de instalar

Atualiza sozinho.

O Argus procura versão nova ao abrir e a cada 5 horas. Quando ela fica pronta, aparece “Atualizar para” no canto da barra de título: um clique e o app reinicia atualizado.

  • As permissões do Mac continuam valendo entre versões
  • No Windows, o instalador novo roda em modo silencioso
  • Notas de cada versão no GitHub
Terminal
# abra a pasta atual no canvas, como o code . do VS Code
$ cd ~/projetos/meu-app
$ argus .

Todas as versões e as notas de cada uma ficam em github.com/ffernandomoraes/argus/releases.

Construindo o jeito aberto de acompanhar agentes de código.

O Argus é a base para trabalhar com vários agentes ao mesmo tempo, com tudo à vista e na sua máquina.
