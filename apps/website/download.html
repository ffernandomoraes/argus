Mac and Linux

Or install from the terminal.

Downloads the latest version, puts it in the right place and opens it. Run it again to update. On Mac, this way the app opens without the unidentified developer warning.

Terminal 
$ curl -fsSL https://raw.githubusercontent.com/ffernandomoraes/argus/main/install.sh | sh

Installation

Step by step.

  1. 1

    Download the .dmg

    The Argus-version-arm64.dmg file, from the button above.

  2. 2

    Drag it to Applications

    Open the .dmg and drag Argus into the Applications folder.

  3. 3

    Allow it the first time

    The app isn't notarized by Apple. In System Settings › Privacy & Security, click Open Anyway.

  1. 1

    Download the installer

    The Argus-Setup-version.exe file, from the button above.

  2. 2

    Open the file

    The first time, Windows shows “Windows protected your PC”. Click More info › Run anyway.

  3. 3

    Install Git

    Git for Windows powers the changed files list and the diff. The app's welcome screens check it for you.

  1. 1

    Download the AppImage

    The Argus-version-x86_64.AppImage file, or use the terminal command above.

  2. 2

    Make it executable

    Run chmod +x on the file and open it. On first launch, Argus adds itself to the app menu.

  3. 3

    Have git installed

    Your distribution's git powers the changed files list: sudo apt install git.

Before you start

What you need.

Claude Code

Argus uses the claude on your machine and your subscription. If you don't have it yet, the welcome screens install it in one click and sign you in.

Git

For the branch, uncommitted files and the diff. On Windows, Git for Windows; on Linux, your distribution's.

Other agents, if you want

Codex, Gemini CLI and Cursor CLI work too. Connect them in Settings › Accounts.

After installing

Updates itself.

Argus checks for a new version when it opens and every 5 hours. When it's ready, “Update to” appears in the corner of the title bar: one click and the app restarts up to date.

  • Mac permissions carry over between versions
  • On Windows, the new installer runs silently
  • Release notes for every version on GitHub
Terminal
# open the current folder on the canvas, like VS Code's code .
$ cd ~/projects/my-app
$ argus .

Every version and its release notes are at github.com/ffernandomoraes/argus/releases.
