?Tutorial · Design mode

Adjust a screen by commenting right on it

Open your project's page in Argus and pin comments to its elements.

Intermediate5 min read

Help › Design mode

  1. 1Turn on design mode

    It's an experiment: enable it in Settings › Experiments › Design mode.

  2. 2Open a design

    Right-click the folder › New design. Choose New prototype to describe a screen from scratch, or Existing screen to adjust a page you already have.

  3. 3Start the server

    The project's server doesn't start on its own: click Start server. The page opens inside Argus, with the chat right next to it.

  4. 4Comment

    Turn on Comment, click the element you want to change and type. The bubbles stay pinned to their elements.

  5. 5Send

    Your comments go out with the next message, along with each element's path and a text snapshot of the screen. Claude then updates the project's code.

Tip

Switch between Desktop and Mobile at the top, and use Ctrl R (⌘R on Mac) to reload just the page.
