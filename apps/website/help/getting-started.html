Getting started: install Argus and open your first project

From installation to your first Claude Code conversation on the canvas.

Beginner5 min read

Help › Getting started

  1. 1Download and install

    Grab the build for your system on the download page. On Mac and Linux you can also install from the terminal:

    curl -fsSL https://raw.githubusercontent.com/ffernandomoraes/argus/main/install.sh | sh

  2. 2Follow the welcome screens

    The first time you open Argus, a short welcome walks you through the app in 5 steps. The last one sets everything up: it installs Claude Code in one click (using Anthropic's official installer), checks for Git on Windows and signs you in to your Claude account.

  3. 3Open a folder

    Click New folder in the canvas menu (Ctrl P (⌘P on Mac)) and pick your project folder. It becomes a block showing the git branch and the most recent conversations.

    Already in the terminal? Run argus . inside the project. It works like code . in VS Code.

  4. 4Start your first conversation

    Click the + above the folder. The chat opens in the side panel with the same CLAUDE.md, settings and MCPs you use with Claude Code in the terminal. Type your request and send it.

Tip

Conversations you already started in the terminal or in VS Code show up in the folder, each with its status.
