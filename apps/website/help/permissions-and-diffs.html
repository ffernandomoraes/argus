?Tutorial · Chats

Review every edit before you accept it

Permissions, file diffs and each chat's permission mode.

Beginner4 min read

Help › Chats

  1. 1See what the agent did

    Every tool call becomes a line in the chat: Read, Create file, Edit, Command. Next to each one, the number of lines added and removed.

  2. 2Open the diff

    Click an edit line to see each file before and after, with removed lines in red and new ones in green.

  3. 3Approve or deny

    When the agent asks for permission, the request shows up in the chat with the full command, in the color of the folder's group. Approve, deny or answer the question.

  4. 4Pick the permission mode

    At the bottom of the message box, choose the chat's permission mode. Each chat remembers its own.

Tip

Click "Command" to see the full input and output of every command the agent ran.
