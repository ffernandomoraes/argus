Terminals and the project server on the canvas

Open terminals next to your folders and start the server with one button.

Beginner3 min read

Help › Terminals

  1. 1Open a terminal

    Right-click the folder › New terminal here › Shell or Claude Code. The terminal opens on the canvas, already in the right folder.

  2. 2Make it bigger when you need to

    Use focus mode in the terminal header, and Ctrl + (⌘+ on Mac) / Ctrl - (⌘- on Mac) to change the font size.

  3. 3Start the project server

    The ▷ button above the folder runs the dev or start script from package.json and shows the port.

  4. 4See what's still running

    Open Running servers (Ctrl Shift S (⇧⌘S on Mac)) for a list of everything the agents left running, with shortcuts to open or stop each one.

Tip

On Windows the terminal uses PowerShell, and projects inside WSL open in their distro.
