◎For teams

Many devs, many agents, one way of working.

Everyone on the team runs Argus on their own machine, with the company account. What makes the agent work well (the project's agents, memory and rules) lives in the repository, the same for everyone.

What changes for the team

Team standards, with no server in between.

No central dashboard to maintain: Argus uses the Claude Code on each machine and the files your team already versions.

A company account per group

The Work group uses the company account; the Personal group uses yours. The group's folders, terminals and chats inherit the right account, and each one's usage limit stays visible.

Workspaces

One canvas per client, product or squad. Switch workspaces without mixing up projects and chats.

Agents in the repository

Agents in .claude/agents inside the project work for everyone who opens the folder. Call one with @name in any chat.

Project memory

The project's CLAUDE.md, versioned in git, gives everyone's agent the same context. Argus lets you edit it right in the app.

Parallel tasks

Each task in its own git worktree, so no agent steps on another's work. Experimental: turn it on in Settings › Experiments.

The right agent for each job

Claude Code, Codex, Gemini and Cursor on the same canvas. With the orchestrator (experimental), a chat hands off steps to another agent.

How to adopt it

From the first dev to the whole team.

  1. 1

    Install it on each machine

    Everyone downloads Argus and signs in with the company Claude account. No server to set up.

  2. 2

    Version the context

    Put the CLAUDE.md and the project's agents in .claude/agents in the repository. Everyone starts with the same finely tuned agent.

  3. 3

    Split by group

    Set up the team's groups on the canvas, each with the right account, and one workspace per product or client.

Control and security

Your code stays where it always was.

Argus runs locally, with no server in between. Chats go to the model the same way they would from the terminal, and every action goes through the permissions you set.

  • Permission mode per chat
  • Permission requests with the full command and the diff
  • Everything the agent does is visible in the chat
  • Open source, so your team can audit it

Questions from teams

What people usually ask before bringing Argus to their team.

Is there a paid plan for teams?

No. Argus is free. Everyone uses their own Claude subscription or the company account, just as they would in the terminal.

Can I use Argus at work?

Yes. The license is MIT with the Commons Clause: using it, including at your company, is allowed. What it prohibits is selling Argus or services built from it.

Does the team share the canvas?

No: each person has their own canvas, on their own machine. What's shared is the repository, with the project's CLAUDE.md and agents.

Does it work if some of the team is on Windows and some on Mac?

Yes. There are versions for macOS, Windows and Linux, and projects in WSL run inside the distro.
